# 또박키즈 (TtoBak Kids)

어린 아이들이 한국어 발음을 재미있게 연습할 수 있도록 만든 간단한 웹 앱입니다.

## 기능
- 오늘의 미션 문장 랜덤 선택
- 문장 듣기(TTS)
- 마이크 녹음 + 브라우저 음성 인식(ko-KR)
- 목표 문장과 인식 문장 유사도 기반 점수화
- 학부모용 연습 히스토리 표시

## 실행
정적 파일이라서 아무 서버에서 바로 실행할 수 있습니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속 후 사용하세요.

## 참고
- 음성 인식 정확도는 브라우저 엔진에 따라 다릅니다.
- 점수는 Levenshtein 거리 기반의 간단한 예시 모델입니다.
